About MeshPay (upiSETU)

Academic Prototype Disclosure: MeshPay is an educational simulation and engineering prototype designed to study offline payment instruction delivery over store-and-forward delay-tolerant networks. It is NOT connected to the live NPCI switch or commercial bank clearing networks.

Open-Source Attribution: This project is built on the foundation of the open-source repository perryvegehan/UPI_Without_Internet.

Key Upgrades in upiSETU: Real Web Crypto RSA-2048-OAEP + AES-256-GCM hybrid cryptography, zero plaintext PIN persistence (on-device SHA-256 hashing), dual-tier idempotency (ciphertext SHA-256 + relational semantic nonce deduplication), persistent RSA key storage, file-based relational H2 persistence, continuous camera video QR decoding, and a structured 6-part experimental testing laboratory.
